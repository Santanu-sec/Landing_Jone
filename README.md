# ☁️ Azure Landing Zone using Terraform

### Infrastructure as Code | Cloud Architecture | DevSecOps

Welcome to my Azure Landing Zone project!

This repository demonstrates my hands-on learning and implementation of Azure cloud infrastructure using Terraform, Infrastructure as Code (IaC), and DevOps best practices.

## 👨‍💻 About This Project

The goal of this project is to design and deploy a scalable, secure, and reusable Azure Landing Zone using Terraform modules.

## 🛠️ Technology Stack

- Microsoft Azure
- Terraform
- Azure DevOps
- Git & GitHub
- Azure Virtual Network
- Network Security Groups
- Azure Key Vault
- Azure Monitor
- Log Analytics

## 🏗️ Architecture Components

- Resource Groups

- Network Security Groups

- Azure Key Vault
- Monitoring and Logging
